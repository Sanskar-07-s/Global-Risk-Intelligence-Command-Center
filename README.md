[![Three.js](https://img.shields.io/badge/Three.js-3D-black.svg)](https://threejs.org/)

An AI-powered, multi-domain global risk intelligence platform featuring an interactive 3D command interface, real-time data fusion across natural hazards, severe weather, cyber threats, and geopolitical instability, explainable multi-factor risk scoring, and a cited AI Intelligence Desk.

---

## Workspaces
1. **Global Operations Center:** Immersive 3D Earth, real-time event markers, alert severity matrix, and freshness telemetry.
2. **Threat Intelligence:** Spatial threat clusters, CISA KEV cyber vulnerability streams, and temporal progression.
3. **Intelligence Knowledge Graph:** Multi-entity network linking incidents, affected critical infrastructure, nations, and sectors.
4. **Risk Analytics:** ECharts interactive distributions, dimensional score breakdown, and geopolitical vulnerability comparisons.
5. **Scenario Laboratory:** Analyst simulation sandbox evaluating cascading supply chain, energy, and humanitarian disruptions.
6. **AI Intelligence Desk:** Gemini-powered analyst synthesizing grounded, cited operational briefs from retrieved events.
7. **Data Fusion & System Health:** Live telemetry on external connectors (USGS, NASA EONET, FIRMS, CISA, Open-Meteo, GDELT).
8. **Reports & Case Management:** Investigation notebook, incident timeline builder, and executive brief export.

---

## Quickstart

### Prerequisites
- Node.js 18+ (Node 20+ recommended)
- Python 3.11+

### Installation & Execution
```bash
# Install root dependencies
npm install

# Start both backend and frontend concurrently
npm run dev
```

Frontend will run at: `http://localhost:5173`  
Backend API will run at: `http://localhost:8000`  
Interactive Swagger docs: `http://localhost:8000/docs`
