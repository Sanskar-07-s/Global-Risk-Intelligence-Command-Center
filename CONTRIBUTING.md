# Contributing to GRICC

Thank you for contributing to the Global Risk Intelligence Command Center.

## Code Standards
1. **Python / Backend:** Follow PEP 8 and use type hints across all endpoints, models, and connectors.
2. **Frontend:** Strict TypeScript, ESLint rules, clean component separation, and Tailwind styling following the obsidian/glassmorphic design system.
3. **Tests:** Every new connector or scoring algorithm must include unit tests.
